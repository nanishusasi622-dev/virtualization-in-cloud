# ☁️ Virtualization in Cloud Computing

## 📌 Project Overview

**Virtualization in Cloud Computing** is a Python-based simulation project that demonstrates how physical computing resources can be divided and allocated to multiple **Virtual Machines (VMs)**.

The project simulates a physical server containing **CPU and memory resources**. A hypervisor manages these resources and allocates them to multiple virtual machines.

The program also calculates resource utilization and displays graphs for CPU and memory allocation.

---

## 🎯 Objectives

* Understand the concept of virtualization in cloud computing.
* Simulate multiple virtual machines on a physical server.
* Allocate CPU and memory resources to VMs.
